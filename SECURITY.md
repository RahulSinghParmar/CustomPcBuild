# Security policy

The latest stable release is supported. Older coursework snapshots do not receive fixes.

Use [GitHub private vulnerability reporting](https://github.com/RahulSinghParmar/CustomPcBuild/security/advisories/new) if enabled. Otherwise contact the maintainer at the email on their [GitHub profile](https://github.com/RahulSinghParmar). Do not publish sensitive details in a public issue.

The app runs locally without network or credential features. CSV export writes only to a new path explicitly provided by the user. Hardware recommendations require independent verification before purchasing.
