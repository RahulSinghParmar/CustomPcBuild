# Changelog

## 1.0.0 — 2026-10-23

First packaged release of the console application.

### Added
- Working express, custom and random builders with office, gaming and editing purposes.
- Seven-category component model and 17-entry illustrative INR catalog.
- CPU socket, RAM, case, graphics and PSU validation.
- Tax-inclusive budget enforcement, decimal money calculations and CSV export.
- Validated input, graceful EOF, glossary, demo and version commands.
- Dependency-free JDK build, regression tests and Windows/macOS/Linux CI.
- User, design, contribution and security documentation.

### Changed
- Replaced static shared state and parallel arrays with immutable records and separate builder logic.
- Replaced `Build.MainMenu` with a runnable Java 17+ JAR.
- Removed tracked IDE configuration and obsolete implementation files; prior versions remain in Git history.

### Limitations
- Demo prices/specifications; no retailer integration or benchmark predictions.
- Exact BIOS, connector, clearance and vendor-specific checks are outside this release.
- Quotes exclude OS licenses, peripherals, shipping and assembly. Import is future work.
